# Termius (https://termius.com)

> Termius is a modern SSH client designed to improve productivity and collaboration for DevOps professionals, network engineers, and infrastructure teams. It provides secure remote access, shared credentials, team vaults, autocomplete, and session organization tools — all with cross-platform support on iOS, Andrdoid, iPad, Windows, Linux, MacOS.

## Website

- https://termius.com: Main site and access point.
- https://docs.termius.com: Documentation.
- https://support.termius.com: Help center and support knowledge base.

## About Us

Termius is built for modern infrastructure teams who want to manage servers and remote systems more efficiently. From solo sysadmins to enterprise DevOps teams, Termius makes it easy to connect, collaborate, and secure infrastructure. It works across macOS, Windows, Linux, iOS, and Android.
